# 金庸群俠傳

開放式武俠角色扮演。你在揚州城外醒來，身無長物，要在江湖上湊齊十四部秘笈，最後上華山之巔。

零依賴的純 ES 模組，開 `index.html` 就能玩（需經 http 伺服器載入模組）。

```bash
npm run serve     # http://localhost:8123
npm run verify    # 數值驗證：資料完整性、戰鬥平衡、主線可通關
npm run smoke     # 無頭瀏覽器實際點按介面（需 macOS 上的 Chrome）
```

## 玩法

- **江湖**：點地圖上相鄰的地點行走，耗天數與體力。城鎮有客棧與商鋪，各處可尋訪同伴、練功。
- **戰鬥**：方格戰棋。依輕功累積行動值出手，每回合可先移動再出一招。
- **武功**：秘笈需**資質**足夠才學得會，每人至多十門，靠實戰精進到第十層。內功是被動的，直接抬高氣血、內力與攻防。
- **同伴**：十八位可招募，多數看你集了幾部秘笈；也有看道德與聲望的。隊伍上限六人。
- **主線**：十四部秘笈集齊，華山之巔的路才開。

## 結構

```
src/data/    skills.js 武功 · items.js 物品 · chars.js 人物 · world.js 地圖
src/core/    rng 確定性亂數 · rules 數值規則 · battle 戰棋引擎 · ai 戰鬥 AI · game 江湖狀態機
src/ui/      app.js 主控與面板 · battleui.js 戰鬥畫面
tools/       verify.mjs 數值驗證 · uismoke.mjs + uitest.js 介面煙霧測試
```

`src/core/` 不碰 DOM，Node 可直接載入——平衡就是這樣調出來的。

## 平衡是怎麼定下來的

`tools/verify.mjs` 裡有一個會自己玩的機器人：它照路線行走、補給、學秘笈、招同伴、打頭目，
輸了就練級再來。跑十六顆不同種子，逐關記錄「平均嘗試次數／當時等級／第幾天」。
所有數值都是照這張表改出來的，不是手感。它抓到過的真問題：

- 開場一人打三個潑皮必敗——早期敵人血量相對主角傷害過高。
- 主角練到破關只有十級，同伴全包了——經驗分配讓主角變成路人。
- 武當山的隨機遭遇比該地頭目還強，等級不夠的隊伍連練級的路都被自己堵死。
- 玄冥二老同時掛在古墓與武當兩關。

`tools/uismoke.mjs` 則用無頭 Chrome 真的去點按鈕、點畫布格子打完一場仗，
斷言的是數字（隊伍人數、天數推進、秘笈入手、回合有沒有前進），不是截圖。
